## 4. 故障注入：检查测试本身是否有效

测试全部通过，只能说明测试过了，不能说明测试是对的。所以在仓库外的副本里故意改坏 15 处关键逻辑，看对应的测试会不会失败，改完再恢复。

| 改坏的地方 | 被哪类测试抓住 |
| --- | --- |
| 用户说中文就把国籍记成中国 | 规则引擎的标准用例 |
| 已经回答的信息被"不确定"覆盖 | 档案合并的单元测试 |
| 修正信息时不保留原来的值 | 档案合并的单元测试 |
| 已标为"不确定"的问题继续追问 | 追问逻辑的单元测试 |
| 不管用户说什么都返回同一个结果 | 规则引擎的标准用例 |
| 没有孩子也生成入学步骤 | 计划生成的单元测试 |
| 已取消或被替代的回复仍写入结果 | 回复任务的集成测试 |
| 能访问别人的咨询 | 接口的集成测试 |
| 翻页时新消息插入导致重复 | 接口的集成测试 |
| 重复提交产生重复消息 | 接口的集成测试 |
| 服务重启后不恢复未完成的回复 | 回复任务的集成测试 |
| 实时连接不校验来源 | 实时推送的集成测试 |
| 页面不显示免责声明 | 浏览器测试 |
| 信息不足时也允许提前生成计划 | 接口的集成测试 |
| 数据还没保存成功就推送给页面 | 实时推送的集成测试 |

15 处全部被抓住，每处都确认了"改坏的代码确实被执行到、目标测试失败、恢复后重新通过"。当时还发现免责声明只检查存在、没有检查可见性。QA 随后补充可见性断言，3 个相关浏览器用例回归通过，见[可见性补充回归记录](../qa/checklists/disclaimer-visibility-39c6bd87.md)。

## 7. 模拟面试官探索式验收

另开一个 AI 窗口，只读 README、不看代码，在真实浏览器里扮演第一次拿到项目的面试官，按 5 个主题自由探索：第一次使用、对话体验、计划、多页面与恢复、出错时的表现。

共发现 15 条问题，修复后由同一个窗口回归：

- **11 条已修复**，例如：按界面提示输入国籍却被记成目的国；"我能拿到签证吗"没被识别成专业问题；说"已经有医疗保险"被当成想咨询医疗；"计划半年后出发"没被识别；信息完整时生成计划没有提示"生成后不能再补充"；不同页面上的计划数量不一致；两份计划卡片看起来一模一样。
- **4 条按决定保留**：用户说"出发时间还不知道"时，系统保留之前记下的时间（有意的设计，避免"不确定"覆盖有效信息）；只做税务的单人，补全信息前后计划步骤相同；资料来源只有机构名称、没有链接；README 开头缺少产品介绍（已在本次文档中补上）。

## 8. 人工验收

在最终版本上亲手验收（主体在冻结前完成）：

- **正常流程**：登录；用题面的例子从开始咨询走到生成计划、打印预览；过程中改口纠正信息、对某个问题回答"还没想好"、信息不全时提前生成；刷新后对话、档案、计划都在。
- **不同情况**：不同国籍和家庭情况生成的计划确实不同；没有详细资料的国家（智利）给通用清单；问税额、开公司等专业问题时不给结论；同一个咨询中途切换理解方式。
- **异常和边界**：回复中途停止、补充一句、直接重启服务；服务停掉期间继续发消息；两个标签页同时打开（一边发消息另一边同步，切走后收到回复有未读红点和浏览器标签提醒）；只回复一个数字"2"、乱打字母、打错国家名；换一个用户登录，并直接打开别人的咨询链接，确认看不到。
- **真实模型**：真实 DeepSeek 和本地模型各走一遍，本地模型严格按 README 的步骤配置启动。

空消息和超长文本没有亲手试，由 QA 的自动化测试和探索式验收覆盖。

**冻结前修复的 4 个问题**（修复后在新版本上逐条复查通过）：

| 问题 | 处理 |
| --- | --- |
| 规则模式不认识"美利坚"等国家全称 | 补充常见国家的别称 |
| 自己发消息时，不管在看哪里，界面都瞬间跳到底部 | 改为平滑滚动；收到别的新消息时，只有停在底部附近才跟随 |
| 正在追问时只回复"2"，系统说"与出海无关" | 改为提示"没能识别出新信息"并重新追问 |
| 没配大模型时，每条打字回复都显示"已回退到规则"，像是出了故障 | 未配置时不再统一显示回退警告；历史记录的显示依据当前配置 |

**冻结后没有修的问题**（已写进 [DECISIONS.md](../DECISIONS.md) 的已知限制）：

| 类别 | 内容 |
| --- | --- |
| 计划内容 | 计划和右侧档案的"未知"一栏会列出与当前诉求无关的项；提前生成时，确认框列出的缺项和计划"未知"栏不一致 |
| 大模型效果 | DeepSeek 偶有多推断、错别字识别不了；本地模型准确率明显更低，会猜孩子人数、换算错时间；11-01 回归中还把用户只提供的“中国籍”误填成当前居住国“中国”，该轮没有回退；大模型给了年龄没给人数时，年龄会被作废重新追问 |
| 规则模式 | 不认识"中华人民共和国"这类全称；乱打的字母会被回复"与出海无关" |
| 显示和措辞 | 专业问题的开头说明固定提签证和税；条件清单里的固定说明（如"收入证明、无犯罪记录等材料要求"）后面也显示"待了解"，像是缺了一项信息；同一轮里"先记录、再因前后不一致作废"会两条并列显示；提前生成的计划标题读着别扭；新建咨询时左栏不会自动切到"进行中"；打开不存在的咨询后，连接状态会短暂显示"同步失败"；从别的标签页切回来，直接点选项时，未读红点要等回复到达才消失；两个标签页同开一个咨询时，未读红点可能闪一下 |
| 排查 | 被校验丢弃的模型输出没有保存，事后不便排查 |
| 测试盲区 | 见第 9 节 |
| 依赖和安装 | `npm ci` 会显示依赖安全提示和 npm 11 的安装脚本警告；已验证环境下安装和启动成功，依赖公告的风险与处理见 DECISIONS |
